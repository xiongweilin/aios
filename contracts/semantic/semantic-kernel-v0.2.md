# Semantic Kernel v0.2

## Ownership

This contract owns only cross-domain meaning. It does not prescribe storage, workflow,
transport, orchestration, agent architecture, or domain lifecycle.

## Epistemic distinctions

- Claim != Evidence.
- Unknown != False.
- Conflict != Error.
- Historical assessment != current qualification.
- Derived evidence does not become independent evidence merely because a model emitted it.

## Intent and governance distinctions

- Goal != Claim.
- Constraint != Goal.
- Proposal != Decision.
- Decision != Authorization.
- Policy satisfaction != Authorization.
- Authorization != Effect.

## Execution distinctions

- Capability != Action.
- Action != Effect.
- Provider success != Effect.
- Effect != Outcome.
- Outcome != Acceptance.
- Work completion != Responsibility discharge.

## Promotion rule

A new concept belongs in the universal semantic kernel only when all of the following hold:

1. at least three materially different domains require the same distinction;
2. collapsing the distinction creates a concrete semantic correctness failure;
3. its meaning is stable across those domains;
4. it does not depend on one World Runtime implementation;
5. it contains no domain-specific policy.

Promotion is explicit and versioned. Observation in the promotion ledger is not itself promotion.
