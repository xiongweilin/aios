# Personal World 1.0 acceptance

状态：**accepted v1.0 baseline**。

Package：`1.0.0`

Provider contract 保持：

```text
personal-world-contracts-v1
```

Consumer conformance 保持：

```text
personal-world-conformance-v1
```

Semantic language 保持严格为 `0.2.0`。

## 冻结语义

Universal record kind 仍严格为：

- fact
- preference
- relationship
- resource-link

v1.0 不新增 Goal、Decision、Authorization、Responsibility、Effect、Outcome、domain lifecycle、agent routing、model routing、secret 或 model-private memory。

## v1.0 closure evidence

0.9 evidence 仍为必要条件：provenance、append-only lineage、revision CAS、PostgreSQL contention、bitemporal reconstruction、多个 DomainPersonalProjection consumer、purpose-limited projection、cross-surface erasure、logical restore 和 physical PostgreSQL restore。

v1.0 另外要求：

1. production instance 绑定一个配置好的 root subject；
2. cross-subject read/write/domain ingress/erasure/bundle surface fail closed；
3. production authentication 使用短生命周期 signed workload assertion，而不是长期 bearer token；
4. erasure 前生成的 physical backup 只能在隔离环境恢复，且 exposure 前必须 replay backup 之后的每个 erasure obligation；
5. public contract name 和四种 record kind 保持不变。

## Freeze rule

1.0 之后，core change 必须有证据证明存在真正新的跨领域 durable personal-context invariant。Domain-specific concept 继续留在各自 Domain Controller。
