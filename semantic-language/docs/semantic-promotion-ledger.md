# Semantic promotion ledger

This ledger records candidates for future universal semantics. A candidate is not part of the
semantic kernel merely because it is useful in one Runtime or one domain.

Promotion requires:

1. the same distinction in at least three materially different domains;
2. a concrete semantic correctness failure when the distinction is collapsed;
3. stable meaning independent of workflow or transport;
4. no dependency on one World Runtime implementation;
5. no embedded domain policy.
