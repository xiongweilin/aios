# Semantic Kernel v0.1

## Ownership

This contract owns only cross-domain meaning. It does not prescribe storage, workflow,
transport, orchestration, agent architecture, or domain lifecycle.

## Epistemic distinctions

- Claim != Evidence.
- Unknown != False.
- Conflict != Error.
- Historical assessment != current qualification.
- Derived evidence does not become independent evidence merely because a model emitted it.

## Intent and governance distinctions

- Goal != Claim.
- Constraint != Goal.
- Proposal != Decision.
- Decision != Authorization.
- Policy satisfaction != Authorization.
- Authorization != Effect.

## Execution distinctions

- Capability != Action.
- Action != Effect.
- Provider success != Effect.
- Effect != Outcome.
- Outcome != Acceptance.
- Work completion != Responsibility discharge.

## Ownership rule

A concept belongs here only when at least two materially different domains require the
same distinction and removing it creates a semantic correctness failure.
