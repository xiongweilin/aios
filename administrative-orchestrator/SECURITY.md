# Security Policy

Please report security-sensitive problems privately rather than opening a public issue.

Use GitHub's private security reporting channel for this repository when it is available. Otherwise, contact the repository maintainer privately through the associated GitHub account.

Include the affected revision, the boundary involved, and enough information to reproduce the problem safely.

Issues involving organizational authority, stale authorization, identity mapping, effect execution, secret handling, replay/reconciliation, verification, production connectors, or accidental promotion of unverified state into completion should be treated as security-sensitive.
